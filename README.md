# コメトレ v3

食事と筋トレの増量記録アプリ（PWA）です。iPhoneのホーム画面に追加して使えます。
AIもAPIキーも使わず、すべてiPhoneの中で動きます。料金はかかりません。

## 入っているファイル

- index.html … アプリ本体
- foods.js / menus.js … 食品の表（約600品。コンビニ・チェーン店のメニューを含む）と筋トレ種目の表（約40種目）
- engine.js … チャットの文章を読み取る仕組み
- manifest.webmanifest / sw.js … ホーム画面用の設定と、オフラインで開くための仕組み
- icons/ … ホーム画面のアイコン

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る（例: kometore）。Publicにする
2. 「Add file」→「Upload files」で、このフォルダの中身をすべてアップロードする（icons フォルダごと）
3. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして保存
4. 数分後に `https://ユーザー名.github.io/kometore/` で開けるようになる

## iPhoneのホーム画面に追加する

1. 上のURLを Safari で開く（最初の1回は電波のある場所で）
2. 開いて数秒待つ（ロゴと同じフォントでホーム画面用のアイコンを作り直します）
3. 共有ボタン →「ホーム画面に追加」→ 名前が「コメトレ」になっているのを確認して「追加」

## チャットの書き方

- 食事: 「昼 パン2枚 卵1個」「夜 牛丼大盛り 味噌汁」「鶏むね肉200g」「食パン4枚切り2枚」
- 量がなければ1人前で計算。「大盛り」「特盛」「少なめ」「半ライス」も使えます
- 消す: 「ちくわなし」「プロテイン削除」
- 直す: 「食パンは4枚切りで計算して」のように「で計算」「だった」「訂正」を付ける
- 筋トレ: 「ベンチ60kg 10回×3」「スクワット80kg 8回 3セット」「懸垂 10回×3」「ランニング30分」
- 体重: 「体重 58.2」
- 別の日: 「昨日の夜 カレー」
- 相談: 「夜は家系ラーメン食べようと思う」→ 記録せずに合計を計算。食べたらボタンで記録
- お店: 「吉野家の牛丼大盛り」「マックでビッグマックとポテトM」「サイゼでミラノ風ドリア」のように店の名前を入れると、その店のメニューの値を使います
  （吉野家・すき家・松屋・なか卯・マクドナルド・モス・ケンタッキー・サイゼリヤ・丸亀製麺・ココイチ・日高屋・王将・天下一品・一蘭・大戸屋・やよい軒・スタバ・コメダ・ドトール・ガスト・ミスド・バーガーキング・セブン・ファミマ・ローソン）

表にない食品は「食事」→「手で追加する」で入力し、「チャットでも使う」にチェックすると、次から名前を送るだけで記録できます（マイ食品）。

読み取れなかった言葉は「推移」→「マイ食品・表になかった言葉・バックアップ」にたまります。「まとめてコピー」してClaudeとのチャットに貼れば、次の版で表に追加できます。

表の値はお店の公式の栄養成分や日本食品標準成分表をもとにした目安です。メニューの改定で変わることがあります。

## データについて

- 記録はiPhoneのSafari（ホーム画面のアプリ）の中にだけ保存されます。11月7日の記録は最初から入っています
- 「推移」→「マイ食品・表になかった言葉・バックアップ」→「書き出す」でバックアップ、「読み込む」で戻せます
- Safariの「履歴とWebサイトデータを消去」をすると記録も消えるので注意
- claude.ai版のコメトレとは記録が同期しません

## 更新するとき

新しい版のファイルで上書きアップロードすれば、次に開いたときに更新されます（記録は消えません）。
